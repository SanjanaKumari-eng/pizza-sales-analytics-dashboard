# 🍕 Pizza Sales Analytics Dashboard

An interactive **Pizza Sales Analytics Dashboard built with Microsoft Excel** to analyze pizza sales performance, customer ordering patterns, product performance, and sales trends.

This project transforms sales data into an interactive business intelligence dashboard using **Microsoft Excel, Power Query, PivotTables, PivotCharts, Slicers, Excel formulas, and VBA automation**.

## 📊 Project Overview

The **Pizza Sales Analytics Dashboard** provides an interactive and visual way to analyze pizza sales data.

The dashboard allows users to explore:

- 💰 Total Revenue
- 🧾 Total Orders
- 🍕 Total Pizzas Sold
- 📊 Average Order Value
- 📅 Monthly sales trends
- 📆 Weekly sales performance
- 🕐 Hourly order patterns
- 🍕 Pizza category performance
- 📏 Pizza size analysis
- 🏆 Best-selling pizzas
- 🔎 Interactive filters and slicers
- 🔄 VBA-powered refresh functionality
- 🧭 Automated navigation between worksheets

The goal of this project is to transform sales data into an **interactive, user-friendly analytical dashboard** that makes it easier to understand business performance and identify sales patterns.

# 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall pizza sales performance
- Identify sales trends over time
- Understand customer ordering patterns

- Identify top-performing pizzas
- Track important sales KPIs
- Create an interactive Excel dashboard

# 🧹 Data Preparation

The data preparation process involved cleaning and transforming the sales data before performing the analysis.

The workflow included:

- Reviewing the raw sales data
- Cleaning and organizing the dataset
- Transforming data using Power Query
- Preparing fields required for analysis
- Creating calculated metrics
- Loading the transformed data for analysis
- Building PivotTables and PivotCharts
- Connecting the analysis to the dashboard
